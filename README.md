# DevOps Control Center

A production-style DevOps Dashboard built using React, TypeScript, and FastAPI.

## Features

- Dashboard
- Pods Management
- Search Pods
- Restart Pods
- Status Badges
- Reusable Components
- Service Layer Architecture

## Tech Stack

Frontend
- React
- TypeScript
- React Router

Backend
- FastAPI
- Pydantic

Future
- Kubernetes API
- Prometheus
- Docker
